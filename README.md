## 🚀 About Me

I'm an **Information Systems undergraduate at Del Institute of Technology**, passionate about building intelligent systems that solve real-world problems.

My interests span **Deep Learning**, **Computer Vision**, **RAG (Retrieval-Augmented Generation)**, **Database Architecture**, and **Full-Stack Web Development**. I love translating complex ideas into clean, functional, and impactful applications.

> 🎓 **Final Project:**
> *Preserving Batak Toba Cultural Heritage Through Deep Learning-Based Ulos Motif Classification and RAG-Assisted Cultural Education*
>
> This project combines **CNN (MobileNetV2)** for motif classification with **Gemini AI** and **n8n RAG pipelines** for interactive cultural education — wrapped in a modern ChatGPT-style web interface.
